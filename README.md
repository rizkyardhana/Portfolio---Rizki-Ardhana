## 🌟 1. Ringkasan & Tujuan Website

Website portofolio ini dibangun untuk memperkenalkan kompetensi profesional **Muhammad Rizki Ardhana** sebagai **Junior Content Editor** kepada calon klien, khususnya pelaku UMKM, brand lokal, bisnis kuliner, produk kecantikan, fashion, serta industri kreatif lainnya.

5. **Akses Publik Satu Link:** Siap dibuka melalui satu URL publik tanpa login, cepat, dan responsif di ponsel pintar (HP), tablet, maupun laptop/desktop.

## 🚀 4. Cara Menjalankan & Membuka Website

### Cara Tercepat (Langsung Buka di Browser):
1. Buka folder proyek ini di komputer Anda.
2. Klik dua kali (double-click) file **`index.html`** pada Google Chrome, Safari, Microsoft Edge, atau Firefox.
3. Website akan langsung terbuka seketika dengan seluruh interaktivitas aktif (navigasi halus, video simulator Reels, modal preview gambar, copy to clipboard, dan tombol WhatsApp).

### Cara Menjalankan Server Lokal (Opsional):
Jika Anda menggunakan terminal:
```bash
# Menggunakan Python bawaan Mac:
python3 -m http.server 3000

# Buka browser di:
http://localhost:3000
```

## 🌐 5. Cara Mempublikasikan Menjadi Link Publik Gratis (Vercel / Netlify / GitHub Pages)

Untuk mendapatkan link website publik (misal: `https://portfolio-rizkiardhana.vercel.app`) yang dapat dicantumkan di CV, LinkedIn, atau bio Instagram:

### Opsi A: Melalui Vercel (Paling Mudah & Cepat - 1 Menit)
1. Buka [vercel.com](https://vercel.com) dan login dengan akun GitHub / Google Anda.
2. Drag & drop folder proyek ini ke dashboard Vercel, atau hubungkan repository Git Anda.
3. Klik **Deploy**.
4. Dalam 15 detik, Anda akan mendapatkan satu link publik HTTPS resmi gratis yang dapat dibuka oleh siapa saja tanpa login!

### Opsi B: Melalui Netlify
1. Buka [netlify.com](https://netlify.com) dan masuk ke dashboard.
2. Tarik (drag-and-drop) folder ini ke area **"Deploy manually"**.
3. Website langsung aktif dengan link publik gratis.

### Opsi C: Melalui GitHub Pages
1. Push folder ini ke repository GitHub Anda (misal: `portofolio-content-editor`).
2. Masuk ke **Settings** > **Pages** di repository GitHub Anda.
3. Pilih source branch `main` dan folder `/ (root)`.
4. Klik **Save**. Website Anda akan aktif di `https://<username>.github.io/<repo-name>/`.

## 🛠️ 6. Cara Mengubah Data Diri & Menambahkan Karya Asli

Semua data telah dipisahkan secara rapi dan modular:

1. **Untuk Mengubah Data Diri, Kontak, dan Naskah:**
   - Buka file **`src/data/portfolioData.js`**.
   - Ganti nomor WhatsApp (`whatsappNumber`), email (`email`), akun Instagram (`instagram`), nama, atau deskripsi sesuai keinginan Anda.
   - Perubahan data ini otomatis berlaku untuk komponen React dan dapat diperbarui di `index.html`.

2. **Untuk Mengganti Gambar Mockup / Karya Canva:**
   - Simpan hasil ekspor gambar Feed (1080×1350 px PNG/JPG) dari Canva ke dalam folder `public/assets/` dengan nama:
     * `feed-1.svg` (atau ganti ke `feed-1.jpg`)
     * `feed-2.svg`
     * `feed-3.svg`
   - Simpan hasil ekspor Story (1080×1920 px) ke `story-1.svg`, `story-2.svg`, `story-3.svg`.
   - Simpan hasil ekspor katalog ke `catalog.svg` atau `catalog.jpg`.

3. **Untuk Mengganti Video Reels CapCut:**
   - Ekspor video dari CapCut (MP4 vertikal 9:16).
   - Letakkan file di `public/assets/reels-video.mp4`.
   - Pada `index.html` atau `ReelsVideo.jsx`, tambahkan tag `<video controls src="./public/assets/reels-video.mp4">` pada area simulator player.
